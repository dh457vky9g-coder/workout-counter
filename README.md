# Workout Counter 설치 안내

## 포함 기능
- 운동 1회 버튼을 누를 때마다 누적 횟수 증가 및 한국어 음성 안내
- 매회 운동 직후 자동 휴식 (기본 60초)
- 휴식 일시정지 / 건너뛰기
- 휴식 종료 전 마지막 5초를 한국어 음성으로 카운트다운
- 운동 종목 및 휴식 시간 변경
- 홈 화면 독립 실행 및 기본 오프라인 캐시

## 아이폰 설치
이 파일들은 웹 앱(PWA) 프로젝트입니다. 아이폰에 설치하려면 HTTPS 주소로 한 번 게시해야 합니다.

1. ZIP 압축을 풀고 파일 전체를 HTTPS를 지원하는 정적 호스팅 서비스(예: GitHub Pages 또는 Netlify)에 게시합니다.
2. 아이폰 Safari에서 게시된 사이트 주소를 엽니다.
3. 공유 버튼을 누릅니다.
4. **홈 화면에 추가**를 선택합니다.
5. 가능하면 **웹 앱으로 열기** 옵션을 켜고 추가합니다.

## 참고
- 홈 화면에 추가한 뒤에는 앱처럼 전체 화면으로 실행됩니다.
- 음성은 iOS의 한국어 음성 합성 기능을 사용합니다. 첫 실행 때 음성 테스트 버튼을 눌러 확인하세요.
- iOS는 백그라운드에서 웹 앱의 타이머 및 음성 재생을 중단하거나 지연할 수 있습니다. 운동 중에는 화면을 켜 둔 상태로 사용하는 것을 권장합니다.
- 실제 App Store 앱이 아니라 홈 화면에 설치하는 웹 앱입니다.
